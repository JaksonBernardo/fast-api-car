# CAR API - Documentação

Bem-vindo à documentação oficial da **CAR API**, uma API REST assíncrona para gerenciamento de carros e usuários.

---

## 🚀 Visão Geral

A CAR API é uma aplicação moderna construída com **FastAPI** e **SQLAlchemy Async**, projetada para fornecer uma interface robusta e escalável para gerenciamento de veículos e usuários. A API segue os princípios RESTful e utiliza autenticação JWT para segurança.

### Principais Funcionalidades

- ✅ **Gerenciamento de Usuários** - CRUD completo de usuários com autenticação
- ✅ **Gerenciamento de Carros** - Cadastro, listagem e manutenção de veículos
- ✅ **Gerenciamento de Marcas** - Controle de marcas/brands de automóveis
- ✅ **Autenticação JWT** - Sistema seguro com tokens de acesso
- ✅ **Banco de Dados Assíncrono** - Performance otimizada com MySQL/MariaDB
- ✅ **Migrações** - Controle de versão de banco de dados com Alembic
